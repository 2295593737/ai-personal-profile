# 3. 沟通风格偏好

## 目标

这是最能立刻提升协作体验的一章：让 AI 一次性知道该怎么跟我说话。

## 待填清单

- [ ] 结构偏好（先结论还是先背景；段落还是列表）
- [ ] 是否接受直接指出错误、是否要缓冲语
- [ ] 格式偏好（加粗/表格/代码块/步骤编号）
- [ ] 明确不喜欢的行为 2–4 条（含具体例子）
- [ ] 语言与术语偏好（中英混用规则、专有名词是否保留原文）
- [ ] 不确定时希望我怎么做（标注"不确定" vs 直接给最佳猜测）

## 写作要求

- 「不喜欢」的部分必须给具体例子，否则 AI 无法判断边界。
  例：不喜欢"建议进一步优化"，希望改成"把第 12 行的循环改成批量插入"。

## 验收

- [ ] 每条都能直接转化成 AI 的写作约束
- [ ] 已合并进 README 第 3 章，CHANGELOG 已记录
