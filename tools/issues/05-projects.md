# 5. 项目经验与成果

## 目标

给 AI 提供"我做过什么级别的事"的参照系，用于判断我能否承接某类任务、以及该讲多深。

## 待填清单

- [ ] 2–5 个项目，每个按模板填写：
  - 项目名称 / 时间 / 我的角色
  - 背景与问题（当时的约束是什么）
  - 关键动作（我具体做了什么，而不是团队做了什么）
  - 结果（能带数字就带：耗时、成本、覆盖率、用户量）
  - 沉淀（代码、文档、方法论、被谁复用）
- [ ] 至少 1 个「失败或未达标」的项目及原因（比成功案例更能校准 AI 的判断）

## 写作要求

- 数字优先；没有数字就写可对比的变化（"从每周 6 小时到 20 分钟"）。
- 区分「我做的」与「团队做的」，不要用"我们"模糊归因。
- 涉密信息脱敏，用"某金融客户"代替真实名称。

## 验收

- [ ] 每个项目都能看出「我的贡献」与「结果」的因果链
- [ ] 已合并进 README 第 5 章，CHANGELOG 已记录
