# 1. 个人简介与背景

## 目标

用最少的事实让任何 AI 在 30 秒内知道我"是谁、在做什么、什么水平"。

## 待填清单

- [ ] 一句话定位（≤30 字，含角色 + 领域）
- [ ] 常用称呼 / 所在城市与时区 / 当前身份
- [ ] 主要领域（最多 3 个，按重要性排序）
- [ ] 背景要点 3–5 条（教育、转行、行业经历）
- [ ] 我不太擅长的 1–3 条（写真实短板，避免 AI 高估我）

## 写作要求

- 只写事实，不写形容词堆砌（"资深""热爱"不提供信息量）。
- 涉及公司/项目名称时，用可公开的说法（如"某电商平台"）。

## 验收

- [ ] 每条都能被单独引用而无需上下文
- [ ] 已合并进 README 第 1 章，CHANGELOG 已记录
