# 4. 常用工具与技术栈

## 目标

让 AI 默认按我的技术栈给方案，而不是给一个我用不了的建议（例如在 Windows 上给 bash-only 脚本）。

## 待填清单

- [ ] 日常工具表（类别 / 工具 / 熟练度）
- [ ] 语言与框架：分「主力 / 能用 / 只读水平」三档
- [ ] 开发环境（操作系统、终端、容器）
- [ ] 数据与基础设施（数据库、缓存、CI、部署方式）
- [ ] 工具偏好 2–3 条（CLI vs GUI、是否追新工具）

## 写作要求

- 熟练度用三档（熟 / 中 / 只读），不要用"精通"。
- 只写最近一年真正在用的，避免堆砌已弃用的技术。

## 验收

- [ ] AI 能据此判断"该给哪个版本的代码"
- [ ] 已合并进 README 第 4 章，CHANGELOG 已记录
