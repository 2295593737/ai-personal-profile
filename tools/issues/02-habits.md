# 2. 工作与学习习惯

## 目标

让 AI 知道什么时候该给我长文、什么时候该给短结论，以及怎么安排任务更贴合我的节奏。

## 待填清单

- [ ] 深度工作时段（具体到小时）
- [ ] 任务拆解习惯（颗粒度、是否先写清单）
- [ ] 沟通节奏（即时响应还是批量处理，紧急如何找我）
- [ ] 学习路径偏好（先跑通 vs 先读文档 vs 先看源码）
- [ ] 协作习惯（接任务时需要哪些信息）
- [ ] 效率雷区 2–3 条（什么情况下我会掉质量）

## 写作要求

- 每条尽量带可验证的细节（时间点、时长、频率），不要写"比较自律"这类无法执行的话。

## 验收

- [ ] 至少一条能被 AI 直接转化成行为（如"上午不要约会议"）
- [ ] 已合并进 README 第 2 章，CHANGELOG 已记录
